# AI絵 → SVG 変換

## 原則

- 意味的な簡略化（描き直し）は**画像生成モデル**の仕事。画力が要る工程をエージェントが代行しない。
- エージェントがSVGパスを**手書きしない**。座標の当てずっぽうで品質が崖落ちする（実証済み）。
  エージェントの仕事は分解・予算設定・プロンプト・計測・合否判定。
- トレースは**フラット化した絵にだけ**かける。slop絵への直接トレースは細線がパスとして
  生き残り、巨大で編集不能なSVGになる（実測：376パス/819KB vs 描き直し後 104パス/167KB）。

## 工程

### 1. 分解（先に決める）

元絵を見て、次を列挙してから生成に入る。

- **保持する特徴**：キャラの本人性を担う要素（髪型のシルエット、目の特徴、代表色、
  アクセサリ、ポーズ、構図）。欲張らない。
- **捨てるディテール**：髪の細線・毛束内部の線、グラデーション、発光、キラキラ、
  微細パターン（回路・レース・反射）、透かし・文字。
- **部位ごとの参照モード**：保持と簡略化はトレードオフなので部位で分ける。
  - 顔・目・特徴アクセサリ：元絵をそのまま参照（コピー寄り）
  - 髪の内部・服のシワ・背景：シルエットと色だけ参照し、中身は新規に描かせる

### 2. 描き直し（画像生成）

`references/redraw-prompt.md` のテンプレートを使い、元絵を添付して画像生成する。
要点は「簡略に」という形容詞ではなく、**部位ごとの数値予算**で指定すること：

- 髪：大きな房のみ（合計7房程度まで）、内部に線ゼロ、飛び出し毛なし
- ハイライト：太い帯1本だけ。筋状にしない
- 塗り：フラット＋影1色まで。グラデなし
- 背景モチーフ：大きな形を数個まで（雷、回路ライン等）
- 鼻：**点1個は必須**。線や形は要らないが、ゼロだと顔の中心が浮く（実証済み）
- 構図・色・ポーズは元絵を保持する

生成後は目視ゲート（下記）を通し、ダメなら部位指定を強めて再生成する。

### 3. トレース（機械処理）

同梱スクリプトで固定設定トレース＋計測する：

```bash
pip install vtracer pillow cairosvg   # cairosvg はプレビュー描画用（任意）
python3 scripts/trace_and_measure.py input.png output.svg --render preview.png
```

固定設定（比較可能性のため変えない）：`filter_speckle=16, color_precision=5,
layer_difference=24, corner_threshold=60, length_threshold=6.0, splice_threshold=45,
path_precision=2, mode=spline, colormode=color`

### 4. 検証ゲート

- **目視**：描き直し版で次を確認する。
  - 髪の内部線がゼロ（房の境界線のみ）になっているか
  - 保持する特徴が全部残っているか（特に目の特徴、鼻の点）
  - 構図と色が元絵から崩れていないか
- **計測**：元絵の直接トレースと描き直し後トレースで、パス数とSVGバイト数を比較して報告する。
  目安はパス数で半分以下。届かない場合は描き直しの予算指定が弱いので工程2へ戻る。

## 落とし穴（実測済み）

- **白黒化を勝手に前提にしない**：「漫画風」は線と塗りの経済性を借りる意味であり、
  色を捨てる指示ではない。ユーザーが言っていない前提を足さない。
- **「simple / minimal」の形容詞だけでは効かない**：モデルの視覚priorが勝って
  ディテールを足す。カテゴリ変換（髪→大きな房の集合）と数値予算で縛る。
- **キラキラは形を変えて残留する**：フラットな星形などになって残ることがある。
  完全に消すなら予算で「装飾モチーフは◯個まで」と数える。
- **頭ごと回転させるな**（手書き・編集時）：パーツを個別に実測座標へ置く方が崩れない。
- **トレース後のSVGはまだアンカー羅列**：コードベースへの組み込み（部品化・名前付け）は
  別工程。本スキルの到達点は「トレース可能なフラット絵」と「計測済みSVG」まで。
